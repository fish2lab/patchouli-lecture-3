## 接口（和第 1 集相同的部分）

- 所有脚本是经典 `<script>`，共享一个全局作用域。**顶层名字带本段前缀**（`S1`、`s1…`；网络是 `NET` / `net…`；琪露诺是 `CIR` / `cir…`），否则撞名整部片打不开。局部变量别叫 `W` `H` `P` `L` `Q` `c`（`c` 作参数除外）。
- 段文件末尾 `scene({ order, key, title, dur, lines, fn, noFlip })`。`fn(c, tau, L)` 是**纯函数**：画面只由 `tau` 决定，不许在闭包或全局里存状态。
- `L` 是当前台词：`L.line`、`L.lineT`、`L.lineP`、`L.who`（`'patchouli'` / `'cirno'`）、`L.mood`、`L.mouth`。**每个角色的嘴型用 `mouthOf(L, 'patchouli')` / `mouthOf(L, 'cirno')`，表情用 `moodOf(L, who, 默认)`**，不要直接把 `L.mouth` 给两个人。
- 台词不改字。可以改时间：`pause`、`hold`、`dur`，或挪 `seq` 的起点。某句的起止：`S1LINES[i][0]` / `[1]`，画面节拍对齐这两个数，别写死秒数。
- 逻辑画面 1920×1080。字幕在 y≈930–1030，不放要读的东西；书脊 `CX` 两侧 ±20 不放字。
- 每帧先 `spread(c, tau)` 画桌面和摊开的魔导书（`BOOK.L` / `BOOK.R`）。段与段之间的翻页由 `film.js` 在段首 0.8 秒画（`turnPage`），不想要就在 `scene` 里写 `noFlip: true`。
- 画具在 `src/kit.js`：`cutPaper`、`rline`、`rshape`、`zh`、`brassPin`、`thread`、`popup`、`vellum`、`spin`、`fade`、`pop`、`sm`、`key`、`win`、`twos`、`writeP`。颜色只用 `P`，再加 `props.js` 里的冰色 `EP2_ICE` / `EP2_ICE_DEEP` / `EP2_FROST`。好坏用压暗的 `P.green` / `P.red`；「惊讶」火花用 `P.red`。
- **不要在逐帧绘制里用 `c.filter`**，会让每帧慢几十倍。大面积 `shadowBlur` 也要省着用。

## 角色

- 帕秋莉：`drawPatchouli(c, { x, y, h, pose, mood, look, tilt, mouth, blink, t, facing, gesture })`，见 `src/character/patchouli.js` 文件头。
- 琪露诺：`drawCirno(c, { x, y, h, pose, mood, look, tilt, mouth, blink, t, facing, gesture })`，见 `src/character/cirno.js` 文件头。骨架里是占位版，A 交付后同一接口换上；**场景只依赖锚点和尺寸，别依赖占位版的长相**。
- 身高：帕秋莉 480–520，琪露诺 420–460，脚底 y ≤ 900。眨眼 `blinkAt(tau)` / `blinkAt(tau, 2)`（两人错开）。

## 交接约定（段与段接得上的关键）

`src/props.js` 里的 `EP2` 是标准站位：`EP2.exam`（试卷，跨书脊）、`EP2.pch`（帕秋莉，左页）、`EP2.cir`（琪露诺，右页，朝左）、`EP2.drop`（水滴落点）。

| 交接 | 前一段最后一帧 | 后一段第一帧 |
|---|---|---|
| 开场 → 第 1 段 | `spread` + `examPaper({ score: 9, frost: 1 })` 在 `EP2.exam` + 两人在标准站位 | 同一张画；霜花从试卷上长成网络（`noFlip: true`） |
| 第 1 → 2 → 3 段 | 网络的「静止态」（`net.js` 里定义，N 写清楚） | 同一张画（`noFlip: true`） |
| 第 3 段 → 结尾 | `spread` + 一滴水 `waterDrop` 正落到 `EP2.drop`（网络已经冻成冰块、化成这滴水）+ 两人在标准站位 | 同一张画；水滴溅开，90 分试卷 `examPaper({ score: 90, frost: 1→0 })` 解冻 |

## 网络（N 负责，D、E 复用）

`src/net.js` 里放「冰的网络」这张图的全部共用画法，D、E 只调用、不复制：结构（左边 3 个输入：剪纸的眼睛、耳朵、书页；各一根线到中间的冰晶求和节点；**线的粗细就是权重**；预测牌、背面朝上的现实牌）、翻牌、红色「惊讶」火花沿线往回跑并让经过的线变粗或变细、追光和暗线、结冰层。接口写在 `net.js` 文件头，参数全部是纯数据（由 `tau` 算出来传进去），不存状态。
