# 画风第二版：克制、写意

2026-09-24 用户审看 v0.1.0 后的意见：「试图做得太实，反而没有真实感。更克制、更写意会更好。帕秋莉比例不对，没有傲娇和娇小的感觉。」讨论后定下：**叙事内容和色彩要简洁；帕秋莉用剪纸风格，可以比纯剪影更精细；油库里语音保留。** 做法照参考项目：先做一段样板（新帕秋莉 + 开场）定画风，再并行重做其他页。

之后的两轮修正（用户，2026-09-24）：
- 参考片的手画粗画框和白底黑框展签不能用，本系列换自己的框架。
- 「黑场 + 吊灯光锥」试过，效果不行，放弃。
- **每页的意象不要做简单：要的是克制、高抽象，不是简单。**

最后定下的舞台：**整个画面是一本摊在深色木桌上的魔导书**（`spread`），旧纸色的两页、书脊阴影、皮面书壳、书页厚度。它不是画框，是一件东西：开场封面翻开，段与段之间真的翻页（`turnPage`），页眉（`pageHeader`）代替展签。书页上用古书的**纸机关**讲事：转盘（volvelle，`spin` + `brassPin`）、立体书（`popup`）、拉条、图钉和线（`thread`）、硫酸纸（`vellum`）、剪纸层（`cutPaper`），再配墨线插图和手写字。

## 从参考片学的「空」

1. 颜色做减法：纸、墨、几级灰，再加一种压暗的颜色。不用渐变、不发光。
2. 一个物件撑一段：一滴墨、一条线、一根引线，在画面里变形成下一个东西，而不是每句换一张新图。
3. 留白 + 生活痕迹：大片空纸，边上一只墨水瓶、一圈茶渍，暗示有人在这里生活，不画全场景。
4. 藏起来不画：只露一顶帽子、一只袖子、一团问号烟，留给观众补。
5. 停住—突然动—再停住：一张画可以撑两三句台词。
6. 统一框架：手画大画框、左上角展签、全片手写字。

## 画面

- **舞台**：`spread(c, tau)` 画桌面和摊开的书（`BOOK.L`、`BOOK.R` 是左右页）。内容画在书页上；夜里的内容可以是一张贴上去的深色纸（`cutPaper` 深色 + 白色墨线/粉笔色字），不是整屏黑场。
- **颜色**：纸、墨、灰三级、帕秋莉紫（`P.purple`）；月牙金（`P.moon`）只用在月牙和极少数强调。好/坏用压暗的 `P.green` / `P.red`，一页里最多出现一种。
- **书页内容**：一页一个核心意象，用一种纸机关贯穿整段、逐句推进、层层加细节——克制（颜色少、字少、不堆图标）但不简单（机关精巧、有层次、有小动作和小笑点）。关键数字手写放大（2–10 分钟、23–4 点、6–8 小时、90+20、150 分钟）。不画带标签的图标阵列、进度条、徽章、UI。
- **字**：霞鹜文楷。段名是书页左上的页眉（`pageHeader`）；字幕是底部一条剪下的纸条。

## 帕秋莉（第二版）

- **娇小**：约 4 头身。帽子蓬大、头大；身体是小小的钟形，肩窄；袖子长到只露指尖；抱的书几乎和上身一样宽。长发垂到脚踝，把身体框在中间。
- **傲娇**：默认半眯的ジト目（上眼睑是一道平直的粗线，盖住瞳孔上三分之一），嘴小。常用的态：抬下巴斜眼看人；得意时闭眼弧线+嘴角一挑；被说中时把书推上来挡住半张脸、脸红；不高兴时鼓腮、侧过脸、冒一个「哼」气团。
- **剪纸**（用户 2026-09-24 定）：帕秋莉是一个剪纸人偶，放在墨线画的书页上。
  - 每个部件是一张彩纸剪出来的：剪刀剪的边是一段段略带折角的直线，不是完美曲线；纸面有细纤维纹；每层纸在下一层上投一道 2–4 像素的软影，所以能看出层次。
  - 层次：后发 → 身体（睡袍，竖条纹是贴上去的细纸条）→ 外袍和袖子 → 脸 → 前发和刘海 → 帽子（荷叶边是一圈剪出来的波浪纸边）→ 月牙（金色纸）、红蓝蝴蝶结（小纸片）。
  - 五官也是剪的：眼睛是深紫纸片 + 一个白色小圆点做高光，ジト目的上眼睑是一条压在眼睛上的深色纸条；嘴是一小片纸；腮红是两片淡粉圆纸。
  - 动作像剪纸动画：部件绕关节（脖子、肩、肘）转动，一拍两帧，停住时纸片有一点点晃。
  - 颜色压暗、克制（`P` 里帕秋莉那组），避免参考项目第一版「彩色剪纸太儿童」的问题：娇小但秀气（身体细、手脚纤细），不做圆滚滚的大头娃娃。
  - 画具 `cutPaper(c, pts, color, o)`（`kit.js`）：剪刀边、纤维纹、投影。
- **走位**：不钉在讲台左边。她是书页上的一个小人：站在页边、坐在一行字上、从页角探头、只伸一只袖子进来指东西。
