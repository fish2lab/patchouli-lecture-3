# 比特数据

`tools/bits/measure.py --build` 生成 `dial.json`、`lines.json` 和 `src/bits-data.js`（动画只读后者）。

- 模型：Qwen/Qwen3-1.7B-Base（bf16），mlx-lm 0.31.3，Apple Silicon 本机跑，2026-09-29。
- 逐字比特：一个 token 盖住几个字时，这个 token 的比特数按字均分；`tokens` 里记着真实边界。
- `guxiang.txt`：鲁迅《故乡》全文（公有领域，来自中文维基文库）。模型每字 0.59 比特，远低于常见估计，多半在训练里见过，只能当「它背过」的例子。
- `new.txt`：2026-09-28 新写的 239 字日常中文，模型没见过。每字 3.46 比特，这是台词里「3.5 比特左右」的来源。短文本上 gzip、xz 比 GBK 还长（字典开销），零阶熵因样本小偏低，这两项只用《故乡》那组。
- `arith`：算术编码上界（⌈Σ−log₂p⌉ + 2）/ 字数，和模型交叉熵几乎相同，说明「预测得多准，就能压多短」。
